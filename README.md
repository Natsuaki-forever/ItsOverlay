# ItsOverlay - 就是遮（v0.1.0α）

Windows 11 x64 轻量级桌面窗口局部遮盖与视觉追踪工具。可以在任意桌面应用窗口上自由添加文字遮盖卡片，用于隐藏敏感信息、标注提示、录制录屏防泄密或自定义桌面小组件。

## 主要特性

- **多应用与多窗口独立管理**：从系统托盘或面板顶部点选任意桌面窗口，支持为同一应用的不同窗口分别保存遮盖配置。
- **窗口锚定 + 视觉追踪**：
  - **窗口固定**：按边缘或中心位置随窗口缩放定位；
  - **视觉追踪**：锁定界面局部特征或边框，即使侧栏折叠、页面滚动或重新打开应用也能自动找回遮盖位置。
- **丰富的外观与动态特效**：
  - **外观与文字**：自定义字体、字号、粗体、对齐、边距、字距、不透明度、圆角半径、卡片边框与屏幕取色；
  - **动态特效**：支持循环滚动（无缝铺满、两侧渐隐）、文字描边、霓虹呼吸发光、双色线性渐变背景、文字投影、斜向流光扫光。
- **轻量原生态**：C++/Win32 常驻引擎 + Rust/Slint 现代编辑面板 + 原生 C++ 视觉识别组件，无需安装 Python 或额外运行库，普通模式下鼠标完全穿透。
- **便捷交互**：默认全局呼出快捷键 `Ctrl+Alt+O`（可在设置中自定义），支持浅色 / 深色 / 跟随系统主题切换、样式复制粘贴与撤销重做。

## 快速上手

1. 解压便携版后，双击运行根目录的 `ItsOverlay.exe`。
2. 从系统托盘或编辑面板顶栏选择需要遮盖的目标应用窗口。
3. 点击左侧 **「新建」** 或 **「连选」**，在目标窗口上直接拖出遮盖区域；按 `Ctrl+Alt+O` 可随时呼出或恢复编辑面板。
4. 右上角 **⚙ 设置** 弹窗中可修改全局快捷键、开机自启、主题模式与打开配置目录。

## 从源码构建

需要 Windows 11 x64、MSVC（Visual Studio Build Tools）、Windows SDK 与 Rust MSVC 工具链：

```powershell
.\tools\prepare-sdk.ps1 -DownloadMissing
.\build-native.ps1 -SlintEditor -VerifyEditor
```

生成的可运行目录位于 `dist\ChatGPTOverlay-Current`。
